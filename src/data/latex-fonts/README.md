# Latin Modern fonts

This directory bundles three unmodified OpenType font files from the Latin Modern collections. The other files in the upstream distributions are omitted. The complete distributions are available from CTAN.

- `latinmodern-math.otf` is Latin Modern Math 1.959. Copyright 2012–2014 by Bogusław Jackowski, Piotr Strzelczyk, and Piotr Pianowski on behalf of TeX Users Groups. [Complete Latin Modern Math distribution](https://ctan.org/pkg/lm-math)
- `lmroman10-italic.otf` and `lmmono10-regular.otf` are part of the Latin Modern family by Bogusław Jackowski and Janusz M. Nowacki, based on Donald E. Knuth’s Computer Modern. Copyright 2003–2021 on behalf of TeX Users Groups. [Complete Latin Modern distribution](https://ctan.org/pkg/lm)
